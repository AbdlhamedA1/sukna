# SUKNA (سُكنا) — Student & Residential Housing Marketplace

> **Graduation Project / Startup MVP**  
> **Initial Scope:** Qena, Sohag, Minya (Upper Egypt)  
> **Current Phase:** Phase 0 — Product Architecture & Documentation Refinement Baseline  
> **Status:** Planning Only — Awaiting Formal Approval Before Implementation

---

## 🎨 Brand Identity Snapshot
- **Primary Brand Color:** Deep Forest Green (`#123B35`) — Represents institutional stability and trust.
- **Accent Highlight:** Warm Orange (`#E88A35`) — Represents warmth, housing, and approachable hospitality.
- **Background Canvas:** Warm Off-White (`#F7F5F0`) — Comfortable contrast avoiding sterile stark white.
- **Surface:** Pure White (`#FFFFFF`) — High-definition cards and form surfaces.
- **Typography:** Charcoal (`#252B28`) with Arabic RTL first-class support (Cairo font family).

## 📖 Master Documentation Directory

All architectural, system design, database, security, and UI/UX planning documents have been established inside the [`docs/`](./docs) directory:
